# Day 45 – Cloud Architecture Design Principles

## Design for Failure
Systems must be built assuming components will fail.
Redundancy and auto-recovery mechanisms are essential.

---

## Scalability
Horizontal scaling enables elastic growth
and improves resilience.

---

## High Availability
Replication and load balancing
ensure system uptime during failures.

---

## Security by Design
Security must be integrated into architecture
using least privilege, encryption, and isolation.

---

## Automation
Infrastructure and deployments should be automated
to reduce human error.

---

## Cost Awareness
Architecture must balance reliability,
performance, and cost efficiency.
