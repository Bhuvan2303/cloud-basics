# Day 44 – Deployment Strategies

## Rolling Deployment
Rolling deployment gradually replaces old instances
with new ones without downtime.

---

## Blue-Green Deployment
Blue-Green deployment uses two environments.
Traffic switches instantly after validation.

---

## Canary Deployment
Canary deployment releases changes to a small
percentage of users before full rollout.

---

## Strategy Selection
Deployment strategies balance risk,
cost, and release speed based on system criticality.
