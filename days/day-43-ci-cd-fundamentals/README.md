# Day 43 – CI/CD Fundamentals

## CI
Continuous Integration automates code testing
and building whenever changes are pushed.

---

## CD
Continuous Delivery and Continuous Deployment
automate the release process to staging or production.

---

## Pipeline
A CI/CD pipeline includes code validation,
testing, building, and deployment stages.

---

## Benefits
Automation improves consistency,
reduces human error, and speeds up releases.

---

## Cloud Role
Cloud engineers integrate CI/CD
with container platforms and cloud infrastructure.
